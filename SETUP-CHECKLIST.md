# Deployment Checklist

- [ ] Extract project folder
- [ ] Open terminal in project folder
- [ ] Run `npm install`
- [ ] Run `npm run dev`
- [ ] Check desktop layout
- [ ] Check mobile layout
- [ ] Run `npm run build`
- [ ] Create GitHub repository
- [ ] Push project to GitHub
- [ ] Import repository into Vercel
- [ ] Confirm production deployment works
- [ ] Add Blueprint WebStudio subdomain in Vercel
- [ ] Add requested CNAME in Porkbun
- [ ] Confirm SSL / domain verification
- [ ] Optional: configure Resend environment variables
- [ ] Replace/handoff approved client images before final production launch
